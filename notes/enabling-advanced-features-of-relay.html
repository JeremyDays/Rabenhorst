Enabling advanced features of Relay

1. To enable Picture Sync:

How to 1. Update to latest Obsidian + Relay (current Relay: 0.5.9) 2. via command palette (cmd+p), do Relay: Enable debugging 3. via command palette, do Relay: Show feature flags 4. Toggle on enableAttachmentSync 5. Reload Obsidian (command palette, Reload app without saving) 6. All collaborators need to perform these same steps

2. To enable Canvas Beta:

⚠️ Warning: risk of data loss

This is beta software. Any canvas file you work with in multiplayer mode could get corrupted or wiped.

  • If you're moving an existing canvas file in, make a backup copy first.
  • If you're working with a multiplayer canvas and it's going great, make a backup copy every once in a while.

------------------------------------------------- How to 1. Update to latest Obsidian + Relay (current Relay: 0.5.9) 2. via command palette (cmd+p), do Relay: Enable debugging 3. via command palette, do Relay: Show feature flags 4. Toggle on enableCanvasSync 5. Reload Obsidian (command palette, Reload app without saving) 6. All collaborators need to perform these same steps

Then you should be able to create a new canvas in your shared folder, and multiplay away.

Note: if you're dragging an existing canvas file in, there might be problems.

  • Make a backup copy first.
  • If the canvas goes blank after you drag it in, try closing the tab and reopening it
